# Store Identity: ร้านเกื้อกูลกัน

- **ประเภทร้าน**: ร้านขายของชำ / ร้านมินิมาร์ท (แบบ 7-11 / CJ Express) และร้านจำหน่ายวัตถุดิบอุปกรณ์เบเกอรี่
- **ไม่ใช่ร้านอาหาร คาเฟ่ หรือร้านกาแฟ**: ห้ามคิดว่าเป็นร้านอาหารตามสั่ง คาเฟ่ หรือร้านกาแฟเด็ดขาด
- **ลักษณะสินค้า**: สินค้าอุปโภคบริโภค, ขนมขบเคี้ยว, เครื่องดื่มบรรจุขวด/กระป๋อง, ของใช้ในบ้าน, วัตถุดิบทำเบเกอรี่ (แป้ง, ยีสต์, เนย, นม, ช็อกโกแลต, แพ็กเกจจิ้ง)
- **การใช้คำ**:
  - ใช้ "จัดเตรียมและแพ็คสินค้าลงกล่อง" (ไม่ใช่ เชฟ/ปรุงอาหาร)
  - ใช้ "สินค้าแนะนำซื้อคู่กัน" หรือ "ซื้อเพิ่มสุดคุ้ม" (ไม่ใช่ สั่งทานคู่กัน)
